# KarkiVerse

A static personal website for Sarwagya Karki.

## Pages
- `index.html` — Home
- `about.html` — My Life photo journal
- `games.html` — Snake, 2048 and Rock, Paper, Scissors
- `voices.html` — browser text-to-speech
- `karkiai.html` — KarkiAI project page, linking to the existing assistant app

## Run locally
Open `index.html` in a browser or serve this folder with any static file server. There is no build step.

## Libraries
GSAP 3.12.5, ScrollTrigger 3.12.5 and Lenis 1.1.9 are loaded from pinned CDNs. The site still renders its content without JavaScript; motion and smooth scrolling are enhancements.

## GitHub Pages
The site is plain HTML, CSS and vanilla JavaScript and can be served from the repository root.
